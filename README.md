# Project ASCEND

## Vision

An Agentic AI Productivity Coach that helps users stay disciplined, plan their day, remember long-term goals, and continuously improve.

---

## Mission

Build this project from scratch while learning Agentic AI.

No tutorial cloning.

Every feature will be implemented only after understanding the concept.

---

- TailwindCSS
- Shadcn UI

Backend

AI

- OpenAI Compatible APIs

Deployment
- Docker
